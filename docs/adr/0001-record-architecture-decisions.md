# 1. Record architecture decisions

Date: 2026-09-20 · Status: accepted

## Context
The project makes many non-obvious choices (data sources, model families, DB portability). Future contributors
need the reasoning, not only the result.

## Decision
Keep short Architecture Decision Records in `docs/adr/NNNN-title.md`: context, decision, consequences.

## Consequences
Small overhead per decision; decisions stay discoverable and reviewable in PRs.
